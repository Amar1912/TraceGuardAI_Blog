# TraceGuardAI_Blog

Autonomous Graph-Powered Fraud Investigation — Technical publication, engineering stories, architecture decisions, and graph intelligence insights from the TraceGuard AI team.

## Tech Stack

- React
- Vite
- React Router
- Tailwind CSS
- Lucide React

## Development

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build
```
